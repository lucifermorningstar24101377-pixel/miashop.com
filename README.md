# miashop.com — فروشگاه فارسی و راست‌چین

فروشگاه نمایشی Next.js برای محصولات آرایشی، مراقبت پوست و عطر.

## اجرا

```bash
npm install
npm run dev
```

## امکانات نسخهٔ اولیه
- رابط فارسی و راست‌چین واکنش‌گرا
- جست‌وجو و فیلتر محصولات نمونه
- سبد خرید و علاقه‌مندی سمت کاربر

## محدودیت‌ها
این نسخه فقط نمونهٔ رابط کاربری است. قیمت‌ها و محصولات نمونه‌اند؛ پرداخت، حساب کاربری، مدیریت سفارش، موجودی و پایگاه داده هنوز متصل نشده‌اند. پیش از فروش واقعی، این بخش‌ها را تکمیل و آزمایش کنید.
